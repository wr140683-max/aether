# Pulse Compliance & Trust Checklist

This checklist is lived, not just written. Review before every major release.

## Dark patterns & fairness
- [ ] No hidden fees or surprise charges
- [ ] Credit / usage costs are visible before action
- [ ] No forced continuity or hard-to-cancel flows
- [ ] No fake urgency, fake reviews, or manufactured social proof
- [ ] No pre-checked marketing opt-ins
- [ ] Equal visual weight for Accept / Reject on consent

## Data minimisation
- [ ] Only collect what is needed for the feature
- [ ] No tracking of unnecessary personal data
- [ ] Clear purpose for every data field
- [ ] Easy data deletion + export

## Third-party SDKs & scripts
- [ ] Inventory of all third-party code
- [ ] Only load after appropriate consent
- [ ] Prefer privacy-friendly alternatives
- [ ] Regular audit (remove unused)

## Accessibility (WCAG 2.1/2.2 AA target)
- [ ] All meaningful images have descriptive alt text
- [ ] Colour contrast ≥ 4.5:1 for normal text, ≥ 3:1 for large / UI components
- [ ] Full keyboard navigation (Tab, Shift+Tab, Enter, Escape, arrows)
- [ ] Visible focus indicators
- [ ] No keyboard traps
- [ ] Form labels and error messages associated correctly
- [ ] Skip links for main content

## Claims & marketing
- [ ] No unsupported performance or “AI will replace X” claims
- [ ] Generated code ownership clearly stated
- [ ] Limitations of the multi-agent system disclosed
- [ ] No fabricated testimonials

## Legal pages present & linked
- [ ] Privacy Policy
- [ ] Terms of Service
- [ ] Cookie Policy
- [ ] Refund Policy
- [ ] Data Deletion instructions
- [ ] Business contact details visible

## Age & children
- [ ] Age gate / notice if required
- [ ] No intentional collection of under-age data
- [ ] Parental consent process if ever needed

## Email
- [ ] One-click unsubscribe on every marketing email
- [ ] Preference centre available

## Fonts & images
- [ ] All fonts properly licensed (or open)
- [ ] Stock / generated images have appropriate licenses and attribution where required
