# Helix Monetization Plan

Goal: Make money while staying better than Emergent on trust and transparency.

## Model

### 1. Free / Open Source (local & self-host)
- Full agent loop
- BYOK only (user pays model providers directly)
- No platform credit tax
- Attracts developers and builds trust

### 2. Hosted Helix (SaaS)
- Managed sandboxes + hosting
- Optional managed keys (convenience)
- Transparent usage dashboard (tokens + $ spent)
- Team workspaces

### Pricing principles (anti-Emergent)
- No opaque credit system that burns on loops
- Show estimated cost *before* running heavy agent steps
- Failed platform-caused loops can be refunded / not charged
- Clear cancel + data export

## Revenue streams
1. Hosted subscriptions (Starter / Pro / Team)
2. Usage-based sandbox minutes (fair, visible)
3. Enterprise self-host support / SSO / audit logs
4. Optional marketplace for community agent skills / templates later

## Trust → conversion
Because we show every step + evidence + real costs, users feel safe spending money.
This is the opposite of the main Emergent complaint.
